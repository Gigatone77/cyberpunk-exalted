[font=Verdana][size=5][b]EXALTED TERMINAL 77 — an offline King James Bible inside Cyberpunk 2077[/b][/size][/font]

[font=Verdana][size=3]The Holy Bible, fully local, in Night City — on [b]two independent surfaces[/b] from one dataset. Take your pick, or install both:[/size][/font]

[font=Verdana][size=4][b]1. EXALTED TERMINAL[/b][/size][/font] [font=Verdana][size=3](CET)[/size][/font]
[font=Verdana][size=3]A full-screen CRT terminal on a hotkey. Browse any book and chapter with the Words of Christ in red, full-text search, a spaced-repetition memory deck, and study notes — over a see-through glass pane whose opacity you dial from the About tab (25-95%, saved).[/size][/font]
[font=Verdana][size=3][list]
[*][b]Hyperkey-first[/b] — [b]TAB[/b] cycles the focus panels (BOOKS → VERSES → SEARCH → MEMORY → NOTES → ABOUT), and each is navigable with the arrow keys: books up/down + Enter to open, verses up/down verse / left-right chapter / PgUp-PgDn / HOME-END, search and notes up/down + Enter to open, memory SPACE reveal + A/H/G/E grade. Keys 1-5 jump straight to a tab.
[*]Open the CET Overlay and the terminal becomes fully interactive (cursor, clicks, keys).
[/list][/size][/font]

[font=Verdana][size=4][b]2. EXALTED BROWSER SITE[/b][/size][/font] [font=Verdana][size=3](in-game web)[/size][/font]
[font=Verdana][size=3]The same Bible as a website inside Night City's own browser. Power on any computer with a browser app, pick [b]Exalted Terminal 77[/b] from the site list, or type the address:[/size][/font]
[center][font=Consolas][size=4][code]NETdir://exalted.terminal[/code][/size][/font][/center]
[font=Verdana][size=3][list]
[*][b]Home[/b] — title page and entry point to the library
[*][b]Library[/b] — all 66 books, 8 per page
[*][b]Book page[/b] — that book's chapter list, 10 per page
[*][b]Reader[/b] — 10 lines per page, with chapter paging plus previous/next chapter, [i]CHAPTERS[/i] and [i]HOME[/i] in the footer
[*][b]About[/b] — version and provenance, in-game
[*]Pure redscript: the pages are built from real in-game browser widgets, so links, hover states and paging behave like any other site in Night City.
[/list][/size][/font]

[font=Verdana][size=4][b]Both surfaces[/b][/size][/font]
[font=Verdana][size=3][list]
[*][b]66 books / 1189 chapters / 31102 verses[/b], with 2028 red-letter verses.
[*][b]Fully offline, no host binary[/b] — no network, no external process, no companion service. Works on any OS. The public-domain KJV (1611 / Oxford 1769) is bundled as JSON in the mod folder and compiled into redscript data modules. Your desktop Bible collection is never touched.
[*][b]Clean text[/b] — the source's cross-reference apparatus, section markers and translator's notes are stripped at build time, so no stray glyphs or margin notes ever reach the screen.
[*][b]Independent[/b] — each surface ships separately and each works without the other. Install one or both.
[/list][/size][/font]

[font=Verdana][size=4][b]Requirements[/b][/size][/font]
[font=Verdana][size=3][b]Only for the terminal surface:[/b]
[list]
[*]Cyberpunk 2077 2.x
[*][b]Cyber Engine Tweaks[/b] (CET) — for the hotkey and the ImGui overlay
[/list][/size][/font]
[font=Verdana][size=3][b]Only for the browser site:[/b]
[list]
[*]Cyberpunk 2077 2.x
[*][b]Browser Extension Framework[/b] — [url=https://www.nexusmods.com/cyberpunk2077/mods/10038]Nexus mod 10038[/url] (0.9.7+), the framework that lets a mod register a custom [i]NETdir://[/i] site into the vanilla browser. Without it the site simply is not listed: the file still compiles, so you get no errors, just no page.
[*]The framework's own prerequisites: [b]redscript[/b], [b]RED4ext[/b], [b]Codeware[/b] (and optionally [b]Mod Settings[/b], which adds an in-game toggle for the framework).
[*][b]CET is NOT required[/b] for the browser site — that surface is pure redscript, no Lua and no ImGui.
[/list][/size][/font]

[font=Verdana][size=4][b]Install[/b][/size][/font]
[font=Verdana][size=3][b]Terminal:[/b]
[list=1]
[*]Unzip into your Cyberpunk 2077 folder (standard CET game-structure layout).
[*]In-game: CET Overlay → Bindings → bind a key for [i]Open EXALTED Terminal[/i].
[*]Press your key to show the terminal; press the CET Overlay key to interact (CET hands mouse and keyboard to the mod UI only while its overlay is open).
[/list][/size][/font]
[font=Verdana][size=3][b]Browser site:[/b]
[list=1]
[*]Unzip into your Cyberpunk 2077 folder. It lands at [code]r6/scripts/EXALTED/[/code].
[*][b]Fully restart the game[/b] — not just reload. Redscript compiles on launch; a script reload is not enough for a new site.
[*]In-game: power on any computer, open a browser, pick [b]Exalted Terminal 77[/b] from the homepage, or type [code]NETdir://exalted.terminal[/code] into the address bar.
[/list][/size][/font]

[font=Verdana][size=4][b]Troubleshooting[/b][/size][/font]
[font=Verdana][size=3][list]
[*]Terminal opens but ignores the keyboard → the CET Overlay is closed. Open it (default Ctrl+Tab) to hand input to the mod.
[*]Site missing from the browser list → Browser Extension Framework not installed, or the game was not fully restarted after installing.
[*]Game will not start, or redscript errors → open [code]Cyberpunk 2077\r6\logs\redscript_rCURRENT.log[/code]. Compilation errors are almost always a framework or Codeware version that is out of date for your game patch, not a fault in this mod.
[/list][/size][/font]
